# AGENTS.md - 英语内容工厂 AI 协同协议与行为准则

> **适用对象**：GPT6extend (ChatGPT Extended 模式 / o1 / GPT-6)、Claude Code、Codex、WorkBuddy AI、以及各类本地与远程开发 Agent。  
> **核心使命**：严守湖南中考英语真题的教辅产品生产规范（`HN-ENGLISH-666`：2022–2026 共 8 套；`HN-ZK-ZHUANXIANG`：2021–2026 共 9 套），确保数据精准、排版零瑕疵、交付闭环。

---

## 一、 必读加载顺序 (Bootstrapping Order)

当任何 Agent 接入本项目时，**必须且只能**按以下顺序加载上下文，严禁直接跳到代码或随意脑补：

1. **`AGENTS.md` (本文件)**：确认项目边界、不可破坏之铁律与安全准则；
2. **`PROJECT_MAP.md`**：理解全景业务架构、模块拓扑图与数据流转链路；
3. **`DATA_SCHEMA.md`**：核验真题语料字段字典、词频清洗契约与数据模型；
4. **`CURRENT_STATE.md`**：确认当前正在进行的迭代里程碑与待办清单；
5. **`02_Projects/HN-ENGLISH-666/项目主控看板.md`**：查看最新业务状态。
6. **`02_Projects/<project_id>/PROJECT_SPEC.md`**（或 `METHODOLOGY.md`）：该项目**生产规范正文**；同目录一并读 `PROJECT.md` / `SOURCES.md` / `ISSUES.md` / `09_runs/`。

> ⚠️ 旧中文路径 `01_项目_湖南中考英语666词/…` 已随 2026-10-09 目录英文化**退役**，不要再按它找文件（见 `PROJECT_MAP.md`）。

## 二、 核心业务不可破坏铁律 (Non-Negotiable Constraints)

1. **单页 A4 极限紧凑排版**：
   - 免费急救包 Top 100 词必须采用 **4 列高紧凑排版（每列 25 词，单页容纳 100 词）**，底部**严禁大面积留白**；
   - 彻底取消每行重复出现的星星（`★★★`），一律改用**梯队大横幅（王者词/高频词/冲刺词）**；
2. **释义极致克制**：
   - 每个单词的中文释义**最多只允许 2 个最核心高频意思**，杜绝罗列七八个低频义项；
3. **重点必须醒目标红**：
   - 序号正红加粗，考频红色括号突出，梯队横幅红底白字，黑白打印对比度高且省纸省墨；
4. **文案去理工化**：
   - 标题统一命名为《湖南中考英语 5年真题核心提分词表 · Top 100》，严禁在用户交付界面出现“真题大数据清洗”、“A4友好版”、“八卷”等技术腔；
5. **封面设计规格**：
   - 小红书封面必须采用 Image 2.5 真实桌面实拍（3:4 比例，晨光微俯拍、木纹桌、手写便利贴、真题试卷衬托）。

## 三、 两级协同闭环机制 (EAC 协议)

1. **第一级 (E1 轻量探索期)**：
   - 遇到新需求、新版式、新文案时，先在 GPT6extend 会话中进行头脑风暴与快速原型验证；
2. **第二级 (E2 资产固化与 GitHub 强上下文闭环)**：
   - 经人工批准后，将代码、模板、Schema 与 ADR 决策固化并推送至 GitHub；
   - 后续任何新会话，**必须要求 AI 依据 GitHub 仓库真实内容进行上下文对齐（RCLP 握手）**，杜绝跨会话遗忘与幻觉漂移。

---

## 四、 完成定义 (Definition of Done)

任何 Agent 完成任务交付时，必须满足：
- [ ] 数据无损且经过校验（无脏词、拼写正确、音标正规）；
- [ ] 页面在浏览器中实际渲染测试通过，页数与边距严格符合预期；
- [ ] 产物落盘至 `02_Projects/<project_id>/`（**现行目录为英文命名**；旧中文目录已退役），并在对应子项目的看板 / `CURRENT_STATE.md` 中更新状态；
- [ ] 涉及重要架构调整时，在 `07_架构决策记录/` 新增 ADR。
