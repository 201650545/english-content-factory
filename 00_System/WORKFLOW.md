# Workflow (内容工厂流水线标准与状态机)

> 版本：**v0.0.1**  
> 声明：**v0.0.1 只定义流水线标准契约与准入准出标准，不进行阶段实现。**

---

## 一、系统标准状态全集 (Standard Lifecycle States)

全系统项目与工件统一遵循以下状态机枚举值，**严禁自行创造含义重复的新状态词**：

| 状态标识 | 含义说明 | 适用场景 / 对应阶段 |
| :--- | :--- | :--- |
| `idea` | 想法与可行性预研期 | 初始提案与立项讨论 |
| `design` | 架构设计与方法论制定期 | 规格制定、字段与流程定义（当前 v0.0.1 状态） |
| `collecting` | 原始材料与语料收集中 | 正在收集真题卷与配套音频/文本 |
| `ingested` | 原始资料归档与验真完成 | 资料已就位并录入 SOURCES.md |
| `cleaning` | 正在清洗去噪与文本结构化 | 正在剥离杂音、题号与排版标记 |
| `analyzing` | 词频统计、共现与加权分析中 | 算法跑批、词频与题型统计中 |
| `review` | 人工/专家质量审核与仲裁中 | 遇到争议题、分词归并或重要度确认 |
| `content_ready` | 教学向解析与核心内容生成就绪 | 例句、词族、释义与考点拓展已齐备 |
| `rendered` | 排版排版文件（Typst/PDF等）已生成 | 视觉成品排版与构建完毕 |
| `approved` | 终审签发通过，准予发布 | 责任编辑或项目负责人最终确认 |
| `published` | 已正式发布 / 上线商用 | 交付用户或对外发布销售 |
| `free` | 商业周期结束，转为公版免费 | 达成到期开放/开源条件 |
| `archived` | 项目历史归档，不再活跃维护 | 全流程关闭，封存数据 |
| `blocked` | 存在未决关键 Issue，生产阻断 | 前置依赖缺失或等待人类决策 |

---

## 二、十三阶段流水线契约 (Pipeline Stages)

流水线总执行序：
```
SOURCE → INGEST → CLEAN → NORMALIZE → ANALYZE → VERIFY → ENRICH → CONTENT → RENDER → REVIEW → PUBLISH → FREE → ARCHIVE
```

---

### 1. SOURCE (原始来源搜集)
* **输入**：真题试卷扫描件、官方教研网站发布文件、录音文件等原始教研资产。
* **操作**：搜集并整理指定年份与地区的官方真题文件，完成文件命名规范化。
* **输出**：存放于 `01_raw/` 的原始文件实体；登记于 `SOURCES.md` 的来源条目草稿。
* **Definition of Done (DoD)**：目标年份与地区的真题文件已全量放置在 `01_raw/`，来源可信度经核对，`SOURCES.md` 建立对应记录。

---

### 2. INGEST (语料摄取与验真)
* **输入**：`01_raw/` 内的原始文件，`SOURCES.md`。
* **操作**：校验文件完整度（MD5/页码/音频完整性），确认授权与合规性，锁定文件为只读。
* **输出**：已校验的原始数据集；`SOURCES.md` 中标记 `是否已验证 = true`、`是否允许进入语料库 = true`。
* **Definition of Done (DoD)**：所有原始卷册完整性通过校验，在 `SOURCES.md` 中完成准入确认，原始数据进入只读保护态。

---

### 3. CLEAN (文本清洗与去噪)
* **输入**：`01_raw/` 中的文本或解析中间件输出。
* **操作**：剥离试卷排版噪点（装订线、准考证号提示、页眉页脚、印刷乱码等），按试卷结构拆分基本段落。
* **输出**：保存于 `02_clean/` 的纯净真题纯文本或 Markdown 中间文件。
* **Definition of Done (DoD)**：无排版乱码，文本可读性 100%，非考试内容噪点全部剔除。

---

### 4. NORMALIZE (分卷结构化与标准化)
* **输入**：`02_clean/` 清洗后的纯净文本。
* **操作**：解析试卷模块化结构，将内容精确归类为：听力原文、完形填空、阅读理解各篇、任务型阅读、语法填空、书面表达等。
* **输出**：存放于 `03_data/` 的分卷结构化 JSON 或标准化试卷对象。
* **Definition of Done (DoD)**：每套真题均具备统一的机器可读结构，题型（sections）与题号映射准确无遗漏。

---

### 5. ANALYZE (词频挖掘与矩阵分析)
* **输入**：`03_data/` 结构化真题数据，以及 `METHODOLOGY.md` 中裁定的分词与统计规则。
* **操作**：执行词形还原（lemmatization）、停用词过滤、词频矩阵统计、题型分布加权计算。
* **输出**：存放于 `04_analysis/` 的词频统计数据表（CSV / SQLite）与频次分布图表。
* **Definition of Done (DoD)**：产出全量词汇的频次（`frequency_total`）、试卷覆盖率（`paper_count`）、年份跨度（`year_count`）及算法综合分（`score`）。

---

### 6. VERIFY (数据交叉验证与校准)
* **输入**：`04_analysis/` 统计表，真题原卷对照抽样。
* **操作**：算法溯源反查，抽样比对高频词在原始试卷中的出现频次与语境，校验有无缩写混淆、人名误算等异常。
* **输出**：验证报告、修正后的统计集，以及推送到 `ISSUES.md` 的异常点。
* **Definition of Done (DoD)**：核心候选词汇抽检准确率达到 100%，争议项目全部在 `ISSUES.md` 记录或由人工仲裁完成。

---

### 7. ENRICH (语料拓展与特征工程)
* **输入**：通过验证的词汇数据子集（如 Top 666 词表）。
* **操作**：关联音标、权威课标词性、契合初中考纲的中文释义、真题高频搭配（`collocations`）与派生词族（`word_family`）。
* **输出**：符合 [`00_System/SCHEMA.md`](file:///D:/Work/English-Content-Factory/00_System/SCHEMA.md) 契约的 `vocab_master` 丰富度数据表。
* **Definition of Done (DoD)**：目标词表每一行记录的必填字段均完成补全，无空缺字段，且来源符合教研依据。

---

### 8. CONTENT (教育内容生成与教学设计)
* **输入**：已补全特征的 `vocab_master` 数据，真题原句上下文。
* **操作**：挑选/提炼最具代表性的真题例句，生成考点深度解析、记忆辅助建议及高频命题陷阱说明。
* **输出**：存放于 `05_content/` 的单词教研讲解资产与出版内容底稿。
* **Definition of Done (DoD)**：666 个词目的解析文案全部生成就绪，例句均源自真题并具备高质量中文译文。

---

### 9. RENDER (版面编排与印刷产物构建)
* **输入**：`05_content/` 内容资产，`06_templates/` 版式模板与样式资源。
* **操作**：执行排版渲染引擎（如 Typst、Markdown 转换器或排版系统），编译生成可阅读与打印的格式文件。
* **输出**：存放于 `07_outputs/` 的排版产物（电子书、PDF、讲义样张等）。
* **Definition of Done (DoD)**：成品排版无溢出、无字体缺失、目录与页码对齐无误，满足阅读与出版版面要求。

---

### 10. REVIEW (质检验收与人工仲裁)
* **输入**：`07_outputs/` 交付物原型，`ISSUES.md`，全套工件链条。
* **操作**：人工教研专家终审（内容正确性、拼写、印刷美观度、教学法合理性）。
* **输出**：审查意见批注，签字确认报告；项目状态推进至 `approved`。
* **Definition of Done (DoD)**：人类审核者正式签署 `approved`，所有阻断级 Issue 彻底清零并闭环。

---

### 11. PUBLISH (渠道发布与商业交付)
* **输入**：经审核批准的成品工件（`07_outputs/`），发布配置。
* **操作**：打包分发文件，部署到发布渠道或生产交付货架。
* **输出**：存放于 `08_publish/` 的交付物清单、发布版本号 Tag 及访问通道。
* **Definition of Done (DoD)**：交付资产成功分发至目标端，版本号与发布日志生效，状态置为 `published`。

---

### 12. FREE (周期到期开放与公版转化)
* **输入**：已发布且达到预定公版免费期限的出版物资产。
* **操作**：移除商业授权锁，调整分发策略为开放获取（Open Access / Creative Commons）。
* **输出**：公开获取渠道链接与免费公版标记。
* **Definition of Done (DoD)**：资产合规转为免费公开，状态变更为 `free`。

---

### 13. ARCHIVE (项目冻结与全生命周期封存)
* **输入**：全阶段完结的项目目录全量资产。
* **操作**：冻结全部写入权限，归纳 Run Logs 与生产指标，生成终态快照并移入 `99_Archive/`。
* **输出**：封存的项目包与全生命周期复盘报告。
* **Definition of Done (DoD)**：项目完整快照移入归档区，状态标记为 `archived`，不再接收增量修改。
