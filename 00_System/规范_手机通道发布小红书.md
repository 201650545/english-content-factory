## 一、什么时候用这条通道

桌面网页版（creator.xiaohongshu.com）出现以下任一情况，**直接切手机通道，不要在桌面磨**：

- `Page.fileChooserOpened not received within 5s` —— 反自动化硬墙，重试无效（实测 3 次含 foreground 全败）
- 手动 `input.files = DataTransfer.files` 返回 `filesSet:0`，或赋值后 input 被 React 重渲染销毁
- 注入的大 base64 随窗口回收丢失

**判死规则：同类报错最多重试 1 次，第 2 次直接换通道。**

## 二、链路（手机浏览器 + 桌面 CDP 接管）

```
桌面 DSH/opencli
   ├─ adb forward tcp:9222 localabstract:chrome_devtools_remote   → 接管手机浏览器 DevTools
   ├─ adb reverse tcp:<PORT> tcp:<PORT>                            → 手机页可 fetch 桌面本地文件
   └─ adb reverse tcp:19825 tcp:19825                              → opencli daemon（备用）
```

前置：
- 手机已开 USB 调试，`adb devices` 显示 device
- 手机装 Kiwi（或其他 Chromium 内核浏览器）
- 桌面跑一个静态文件服务器，暴露要上传的图片（见 `serve_products.py` 模板）

**拔线/重连后 forward/reverse 全失效，必须重跑。**若 `adb devices` 空但设备确实插着，先 `adb kill-server` 再 `start-server`。

## 三、四个关键结论（踩坑换来的）

| # | 结论 | 说明 |
| :--- | :--- | :--- |
| 1 | **手机页的 `input.files` 赋值有效** | 桌面页会被 React 重渲染销毁，手机页不会。这是整条通道成立的根本原因 |
| 2 | 图片走 HTTP 本地回环喂进去 | `fetch('http://127.0.0.1:PORT/x.png')` → `blob` → `new File([blob], name, {type})` → `DataTransfer.items.add` → `input.files = dt.files` + 派发 `input`/`change` |
| 3 | 自研组件必须用**真鼠标事件** | 话题胶囊、内容类型声明下拉，JS `.click()` 和合成 `MouseEvent` 都无效，必须 `CDP Input.dispatchMouseEvent`（mousePressed → 80ms → mouseReleased） |
| 4 | 富文本正文走 ProseMirror | 选区 `selectNodeContents` + `document.execCommand('insertText', false, text)`，写完**必须回读校验** |

## 四、操作顺序（照抄）

1. 建隧道（见上），`node cdp.mjs list` 确认能看到手机 page target
2. 打开创作页：`node cdp.mjs newtab 'https://creator.xiaohongshu.com/publish/publish?source=official'`，等 10s 让登录态就绪
3. 点「上传图文」tab
4. 确认 `input.upload-input[type=file][multiple]` 存在
5. 一次性注入全部图片（顺序 = 数组顺序，就是轮播顺序）
6. 填标题（`input.d-text[placeholder]`，用原生 value setter + 派发 input/change）
7. 填正文（ProseMirror），**回读比对**，不一致就重写，最多 5 轮
8. 挂话题：先用 `Input.dispatchMouseEvent` 点「# 话题」唤起建议胶囊，再逐个点胶囊
9. 勾「笔记含AI合成内容」：先点开「添加内容类型声明」下拉，再点选项（都要真鼠标事件）
10. 截图给自己和用户看，**停在发布按钮前等审核**

---

## 五、四条纪律

1. **外部调用一律后台 job 或短命令**，不写同步重试循环；超时即降级
2. **改完必回读**：标题、正文、图片数、声明状态，逐项 verify 后再报告"已完成"
3. **发布前必须人工审核**：把发布页截图 + 审核单交给用户，用户点头才点发布按钮
4. **拔线即失效**：任何 adb forward/reverse 断掉后，先重建隧道再干活，不要怀疑代码
