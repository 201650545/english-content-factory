## 架构原则与双阶段协同

1. **知识库全中文规范**：除面向机器接口的文件（如 `AGENTS.md`）外，所有业务目录与文档全面采用全中文命名，沉浸式对齐中文母语认知；
2. **两级协同闭环机制 (EAC)**：
   - **第一级 (E1 轻量探索期)**：与镜像站 GPT6extend 模式初步讨论，碰撞方案、生成视觉原型；
   - **第二级 (E2 资产固化期)**：将验证成熟的核心规范与代码入库 GitHub，后续跨会话或多 Agent 协作时，强制 GPT6extend 读取 GitHub 仓库上下文，杜绝遗忘与漂移。
