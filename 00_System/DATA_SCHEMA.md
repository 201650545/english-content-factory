# DATA_SCHEMA.md - 数据字典与契约规范

## 1. Top 100 词条结构契约 (`top100_enriched.json`)

每个词条为一个严格 JSON 对象，字段定义如下：

```json
{
  "rank": 1,
  "word": "make",
  "phonetic": "/meɪk/",
  "freq": 89,
  "meaning": "v. 制作; 使",
  "tier": 1,
  "tier_name": "第一梯队 · 必考王者词 (≥50次)",
  "collocation": "make a difference"
}
```

### 字段说明与约束：
- `rank` (integer): 1 ~ 100 词频排序名次，不可跳号；
- `word` (string): 单词原型，全部小写纯英文字母；
- `phonetic` (string): 国际音标，使用 `/.../` 斜杠包裹；
- `freq` (integer): 5 年 8 套真题中出现的严格统计总次数；
- `meaning` (string): 词性前缀 + **最多 2 个中文高频义项**，以分号 `;` 分隔，严禁冗长解释；
- `tier` (integer): 梯队编号（1: ≥50次王者词, 2: 30-49次高频词, 3: 15-29次冲刺词）；
- `tier_name` (string): 梯队完整展示名称。
