# English Content Factory · 英语内容工厂

> 一个**中考英语备考资料的生产系统**：从真题语料 → 词频数据 → 可打印教辅成品 → 社交媒体发行。
> 本仓是**核心结构与规范**的公开快照，供外部模型 / 协作者阅读理解本项目的工作方式与产品理念。

---

## 一、这个系统是什么

把「一线教研想要什么」翻译成「可复现的生产流程」，核心是三件事：

1. **数据可追溯**——每个数字（词频、出现次数、覆盖套数）都能回源到具体真题，不靠估算
2. **规范先行**——排版、命名、交付形态先定规范，再开工；规范正文只有一份（SSOT）
3. **多模型协同**——不同模型按工位分工（架构推演 / 内容生产 / 审核），每个工位有明确边界

**面向对象**：湖南省初三学生与家长；产品形态为 A4 打印 PDF。

## 三、核心产品与分层理念

### 三层产品线（解决三个不同的问题）

| 层 | 资料 | 解决什么 | 状态 |
| :--- | :--- | :--- | :--- |
| **L1** | 《688词表格速查版》28 页 A4 | 这个词**认不认识** | 已定稿 |
| **L2** | 《用法搭配培优手册》11 页 → 目标 39–45 页 | 这个词**会不会用** | 进行中 |
| **L3** | 训练册（形式待定） | **会不会判断、能不能复测** | 待定义 |

**L2 的分层深度策略**（按数据自带星级）：

| 层 | 词数 | 每页词数 | 每个词给什么 |
| :--- | ---: | ---: | :--- |
| ★★★ 核心 | 82 | 8–10 | 搭配 + 用法 + 辨析 + 例句 + 易错批注 |
| ★★☆ 重要 | 218 | 20 | 2–3 搭配 + 1 句易错批注 |
| ★☆☆ 基础 | 388 | 30 | 搭配 + 中文，不展开 |

### 备考信息的分层（数据可获得性）

| 层 | 含义 | 例 |
| :--- | :--- | :--- |
| **A** 词汇出现 | 现有语料清洗后可直接算 | 词频、覆盖套数 |
| **B** 语言结构出现 | 规则匹配置信度高 | 固定搭配、接格 |
| **C** 真正作为考点 | 需人工标注题号与答案 | 完形线索、选词填空词形变化 |

> 产品优先做 **B+C**，不只做 A —— 词表谁都能做，考法才是差异。

## 四、排版规范（硬性）

### 4.1 视觉系统

| 项 | 规定 |
| :--- | :--- |
| 背景 | **纯白 `#ffffff`**（禁止纸纹、米黄底） |
| 字色 | 正文 `#000`；次级 `#111`；三级 `#2b2b2b`；强调红 `#c00000` |
| 荧光笔 | **只准平面实色，禁止渐变**。黄 `#ffe95c` / 粉 `#ffc2d6` / 蓝 `#bcd9ff` |
| 三色语义 | 黄 = 核心词 / 粉 = 中文释义与用法要点 / 蓝 = 英文固定搭配 / 红笔楷体 = 易错批注 |
| 字体 | 中文正文 宋体；标题 黑体；西文 Times New Roman；红笔批注 楷体 |

### 4.2 版面网格与硬门槛

```
内容区 = 182mm 宽 × 230mm 高
      = 297 − 28(上下边距 14×2) − 21(标题) − 8(页脚) − 10(安全区)
字号底线：正文 ≥ 10pt（主词 12–13pt / 音标 9.5pt / 红批 9.5pt / 标题 15pt）
```

> **★ 硬性要求：每一页填充率必须 ≥ 90%。**
> 达不到时按优先级处理：① 补内容（首选，加真信息）→ ② 放大字号（不低于底线）→ ③ 换版式。
> **禁止**为填满页面而增加无实际价值的文字。

**容量估算公式**：

```
行高 10pt ≈ 4.6mm
H单条 = L × 4.6 + P                    （L=行数，P=上下内边距 mm）
N     = ⌊ (230 + G) / (H单条 + G) ⌋     （G=条目间距 mm）
注意：双列容量不能简单乘二——变窄后英文例句可能从一行变两行，必须重算。
```

### 4.3 音节切分（记忆辅助）

- 符号统一用**中点 `·`**（`im·por·tant`）；不用斜杠（与 IPA 冲突）
- 主重音用**加粗 + 下划线**（黑白打印也能识别），彩色只做增强
- **只用于 3 音节以上 / 易拼错的多音节词**；`make` / `take` / `get` / `look` 这类不拆
- 建议覆盖 30–60 个词，**不做全量程序化切分**（发音音节 ≠ 拼写分段）

## 五、已确认的外部事实（影响产品设计）

**2026 年起湖南省初中学业水平考试英语试卷结构**（湘教考命字〔2025〕3 号，2025-12-22 发布）

| 部分 | 题量 × 分值 | 合计 |
| :--- | :--- | ---: |
| 听力 | 20 × 1 | 20 |
| 阅读 | 15 × 2 | 30 |
| 语言运用 · 完形填空 | 10 × 1.5 | 15 |
| **语言运用 · 选词填空** | **10 × 1** | **10** |
| 综合技能 · 简答和翻译 | 5 × 2 | 10 |
| 综合技能 · 书面表达 | 1 题 | 15 |

**「选词填空」是新增题型（10 分）**——考查词义辨析 + 词形变化 + 语篇线索，正是「单词都认识但选不对」的失分点。

## 六、数据口径红线

1. **词频数字必须回源实测**，不采信推测；口径要写明统计覆盖范围
2. **省卷 / 长沙卷保留地区标签**，不笼统写成"湖南省统考卷"
3. **8 套样本不足以论证"命题趋势"**；宣传避免"大数据预测""押题命中率"
4. **有真题纯文本 ≠ 有商业再版权**；配套练习须自编，并区分"真题原题 / 真题节选 / 依考法编写的模拟题"

## 七、本仓**有意未收录**的内容

为遵守版权与隐私红线，以下内容不在本仓：

- 真题原文、真题扫描件、OCR 文本、逐题解析（**版权材料**）
- 词表 CSV / 词频原始数据（生产资产）
- 成品 PDF/EPUB 二进制
- 运行日志、内部看板、决策记录、外部模型问诊原文
- 任何密钥、凭证、账号信息

本仓只保留**结构 / 规范 / 理念**层面的文档，以及若干**版面样张图**（用于说明设计语言）。
