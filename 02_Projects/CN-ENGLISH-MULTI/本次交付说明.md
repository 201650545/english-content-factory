## 五、筛选口径

1. **抽词**：英文单词（≥2 字母）；序数后缀（`1st/2nd`）剔除；上海卷 `(b)uy` 式提示还原为完整单词。
2. **三分类**：命中 37 万词表 → 词表；首字母大写未命中 → 专有名词；小写未命中 → 判粘连/噪声，否则保留为词表外词。
3. **去噪**：缺空格粘连（如 `tothink=to+think`）按**最少段数**拆开并回填词频；网址/邮箱/文件名片段整类剔除。
4. **词形归并**：复数 / 三单 / 过去式 / 过去分词 / 现在分词 / 比较级 → 原形（含不规则动词表）。
5. **类别**：功能词 / **短词·缩写（长度 ≤2）** / 内容词 —— 内容词表已剔除前两类，避免 `dr / uk / ii` 等缩写污染。
