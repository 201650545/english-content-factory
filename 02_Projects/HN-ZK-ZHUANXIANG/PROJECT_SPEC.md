**适用**：湖南中考英语真题 → **分题型专项练习册（HTML 印刷品）** 的整条生产链（取源 → 文本化 → 切分 → 组册 → 加解析 → 质检 → 出成品）。

### 2.2 四条硬纪律

1. **外部题源编号 ≠ 原卷编号** —— 教习网 / 21cnjy 的题号编排常与原卷不一致（如五选五排 1—5、完形排 6—15）。
   **一律逐题按"内容"映射，禁止按数字对位。**
2. **OCR 掉字母 `o`** —— 教习网预览页是图片 OCR，普遍丢 `o`：`frm`→from、`cvers`→covers、`wrkshp`→workshop、`jy`→joy、`prud`→proud、`fcused`→focused、`bks`→books、`avid`→avoid。**抓取后逐词修复。**
3. **题号 / 选项字母可能缺句点** —— 形如 `11 It's said…`、`A xxx`（无 `.`）。解析器必须容错（见 §3.4）。
4. **每条答案与解析都要留来源文档 ID** —— 写进 `SOURCES.md` §五 / §六，禁止"来源不明"的解析入库。

## 3. 生成器架构（`build_zt.py`）

### 3.1 四大数据结构

| 名称 | 作用 |
| :--- | :--- |
| `PAPERS` | 各卷的行坐标（从 `02_clean/试卷文本/*.txt` 定位各题型的起止行） |
| `ANS` | 答案字典（题号 → 答案） |
| `ANA` | **解析字典**，启动时合并 `analysis_zh.json`（2021—2023 长沙卷）+ `analysis_ext.json`（2024—2026 六套卷）；`setdefault(k,{}).update(v)` 逐键合并，跳过 `_` 前缀的元数据键 |
| `tail()` | 页脚 / 元信息渲染 |

### 3.2 哨兵系统

原文里"段落之间的空行"与"题内填空"在文本化后无法区分，用**哨兵**在清洗阶段打标、渲染阶段还原：

```
GAP   = "\x00GAP\x00"      # 段落分隔
BLANK = "\x00BLANK\x00"    # 题内填空（下划线空位）
```

配套：`tidy()`（清洗）、`render_block_lines()`（渲染时把哨兵还原成 `<div class="gap">` / 下划线）。

> ⚠️ **哨兵用了 NUL 字节**，因此成品必须做 **NUL 残留检查**（见 §5）——渲染漏还原就会把 `\x00` 带进 HTML。

### 3.3 选项提取

`opts_map(paper, key)` —— 从原卷文本抽出**每题**的选项列表，**只作用于选择题段落**：

```python
OPT_SECS = {"阅读A", "阅读B", "阅读C", "阅读D", "完形填空"}
```

结果按 `(paper, key)` 缓存于 `_OPTS_CACHE`，避免重复解析。

### 3.4 OCR 容错解析（关键坑）

老写法 `split_opts()` 要求 `[A-E][.．]\s`，遇到缺句点的 OCR 文本会**把下一题的选项挂到上一题**（2025 湖南省卷 阅读C 的 Q11 选项曾误挂到 Q10）。

修法：新增宽松解析 + 题号容错，**且只在选择题段落启用**：

```python
split_opts_loose()   # 允许 [A-E] 后无句点
_qnum()              # 严格 ^(\d{1,2})[.．] 失败时回退宽松 ^(\d{1,2})\s+(?=[A-Z"'（(])
# 通过 section() 的 loose_q=(key in OPT_SECS) 逐段开关
```

> **为什么必须限定范围**：全域启用会误匹配——「阅读还原」的 `11 It's said…`、2022 长沙卷书面表达尾部的 `1 Public Speakers` 都会被当成题号。

### 3.5 标红流水线 `red_marks()`

解析文本先 HTML 转义，再按正则族标红（`.rd` = `#c00000` + 粗体）：

| 正则 | 命中 |
| :--- | :--- |
| `RE_SEL` | `故选\s*([A-E])` |
| `RE_FILL` | `故填\s*([^。；;，,]{1,40})` |
| `RE_ANS2` | `故答案为\s*(…)` |
| `RE_DA` | `故答\s*(…)` |
| `RE_TR` | `故译(?:为\|成)?\s*[：:]?\s*(…)` |
| `RE_XIANG` | `([A-E])\s*项` |
| `RE_OPTX` | `选项\s*([A-E])` |
| `RE_GLOSS` | 词汇对照串（如 `eyes眼睛；hands手；mouth嘴`） |

### 3.6 解析渲染

- `ana_html(paper, key, only=None)` —— 渲染"导语 + 逐题解析"；**每题解析前插一行** `选项 A. … B. … C. …`（`class="ana-o"`）。
- `ans_html(paper, key)` —— 在答案区每行末尾追加 `ana_html(...)`。
- `_tr_sec()` —— 对 2024—2026 湖南省卷的翻译 **Q40** 单独调 `ana_html(p, "回答问题", only={"40"})`（该题题号在"回答问题"段内）。

## 4. 印刷 HTML 规范

| 项 | 约束 |
| :--- | :--- |
| 形态 | **单文件自包含**（CSS 内联，无外链），可直接打印 |
| 版式 | 分栏；`@media print` 必须包含 `.ana, .ana-tag, .ana-k, .ana-q>b.qn, .rd` |
| 红标 | `.rd{color:#c00000;font-weight:700}` + `.rd{-webkit-print-color-adjust:exact}`（否则打印丢色）；**红标只用于"答案 + 选项内容"，绝不染正文** |
| 解析块类名 | `.ana`（块）/ `.ana-i`（导语）/ `.ana-tag` / `.ana-q`（逐题，含 `b.qn` 题号）/ `.ana-o`（选项行）/ `.ana-k`（答案 key） |
| 来源标注 | 每篇正文标**来源卷别 + 年份**；页脚 / 元信息须写明"**参考答案 + 逐题解析**" |
| 题目 | **只收真题原题，不改写**；题干保留原卷用词 |

## 5. 质检口径（每轮必须现跑，不得抄旧数）

**六个计数**（`class=` 计数法，跑一遍 Python 统计即可）：

1. 解析块数 `class="ana"`
2. 逐题解析数 `class="ana-q"`
3. 选择题选项行数 `class="ana-o"`
4. 答案 key 数 `class="ana-k"`
5. 红标处数 `class="rd"`
6. NUL 字节数（**必须为 0**）+ 成品总体积

**一致性断言**：

- **选项行数 == 答案 key 数 == 选择题题数**（本批 **198 == 198**）
- 12 个成品文件齐备（`00_总览` + 11 专项）
- 解析条目覆盖全部选择题（`ana-q` ≥ 选项行数）

> 收尾结论必须附**当轮跑出来的命令输出**——这是跨项目硬规矩（见 `D:\记忆\通用规范\80-引用校验与证据纪律.md`），没输出就是猜的。
