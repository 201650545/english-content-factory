### 抓取方法（2026-10-10 定型，可复用）

* 工具链：**`opencli`（bridge 到用户已登录的 Chrome）+ B 站官方 API + `yt-dlp`**。
* 判免费：`opencli bilibili video <bvid> -f json` → 解析 `[{field,value}]` 记录，
  取 `requires_payment` / `pay_preview`（均 `false` 才是免费全长）。
* 下载：`opencli bilibili download <bvid> --page N --output DIR --quality best`
  → 同时产出 `.mp4`（视频）与 **`.m4a`（独立音轨）**；**不需要从视频里抽音**。
* 转码：PyAV 把 `.m4a`（AAC 44.1kHz）→ MP3 128kbps。
* **防试看校验（必做）**：转码后比对成品时长与元数据 `duration`，偏差 < 3 s 且 > 60 s 才收录
  —— 杜绝把 180 s 试看片段当全曲（2026-10-10 首轮踩过的坑）。
